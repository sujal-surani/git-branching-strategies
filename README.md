# Git Branching Strategies and Workflows

This repository demonstrates version control workflows using Git.

## Project Scope
* **Initialization:** Configured a local Git repository with a standard `.gitignore`.
* **Branching:** Established a branch hierarchy using `main`, `dev`, and `feature` branches.
* **Collaboration:** Simulated a real-world integration process using Pull Requests to merge feature updates into the development and production branches.
